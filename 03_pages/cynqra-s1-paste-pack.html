S1 by hand

Prompt v2_26sep2026. Ten fresh chats, about an hour, no key and no install. This produces one of the two spike scores the M2 gate is waiting on. The bar is 8 of 10 and it does not move.

Why this page replaced the 25 August one. The old prompt told the model to leave unstated fields empty, and the scorer fails any empty field, so a model that obeyed would have scored zero. The ten objectives, the expected answers, the scorer and the bar are unchanged. No S1 answers existed yet, so no result is affected.

Rules that decide whether the score means anything

A new chat every time.Ten items, ten chats. A reused chat lets item four learn from item three.
Temporary or incognito chat, or memory off.A model that remembers Cynqra or the candidate tracker is not a clean test.
Paste exactly, add nothing.No hints, no context, no telling it what you hope to see.
Never tidy the reply.Not a bracket, not a blank field, not a typo. Prose instead of JSON is a real failure and counts as one.
Retry only when the scorer says so.Each item gets one retry, in a new chat, with the retry block under the item.
