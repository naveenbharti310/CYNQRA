Question. When a customer asks for deletion, what happens to the immutable event history?

Design rule already in force

Event payloads carry no personal data. Each company's data sits under its own keys. That rule is not for counsel to invent. It is already how we build.

Options

OptionHow it worksAsk
1. Key destructionEvents remain. Company keys are destroyed. History becomes unreadable.Does this satisfy erasure duties in first markets?
2. Personal data outside eventsEvents carry references only. Personal data lives in erasable stores.Is this required, or only nicer?
3. HybridBoth. Fall back to 1 if cost dominates.Recommended starting ask.

  • Whether option 1 alone is enough, or only as a fallback.

  • Whether a retention window is required before key destruction.
