# Archive

**What:** history only: earlier plans, experiments, reports and notes. **Why** it is kept: to show how Cynqra got here,
unchanged, without cluttering the documents people work from. **How** to use it: you do not need it to understand,
run or build Cynqra; start with the [README](../README.md).

Kept unchanged for reference: the original canon books and decisions (`00_canon/`), the earlier experiment harness
(`02_harness/`, still used by the `cynqra-spikes` and `cynqra-hf` workflows), the earlier browser reports
(`03_pages/`), and earlier notes, reviews and run logs (`old_docs/`).
