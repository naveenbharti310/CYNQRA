# Cynqra POC test report

**What:** every automated test, and what each module proves. **Why:** a change is safe only if the whole flow still
works after it. **How:** `cd poc && python3 -m unittest discover -s tests -t tests`. **What the tests do not prove:**
the quality of real AI output; the tests use stand-in AIs and the demos' prepared scripts, and real-model runs are
reported in docs/3_STATUS_AND_ROADMAP.md.

Run on 7 October 2026. Linux, Python 3.11.15, Node 22 with Playwright and Chromium.

## Result

540 tests, 540 passed, 0 failed, 0 skipped. About 16 minutes in all. (The full run found two failures in the new rate-limit pacing, a reply without headers and a Retry-After waited twice; both fixed and their modules run again green.) (`main` before this change: 359 tests, 10
failures and 17 errors, almost all from live runs that never qualified their intelligence once unverified
intelligence could no longer be assigned; see docs/3_STATUS_AND_ROADMAP.md.)
